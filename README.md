# javaded.com

Source of my personal website — [javaded.com](https://javaded.com).

I'm Javad. I build software and figure things out along the way. That includes
[Spinyard](https://spinyardhq.com) and ScoutSpin (table tennis, under Buildcue),
and co-founding [Venonwood](https://venonwood.biz/) and
[Dropball](https://dropball-game.ir/).

Built with [Astro](https://astro.build) and Tailwind CSS, deployed on GitHub
Pages. A small Cloudflare Worker + Resend handles the newsletter and contact
form.

## Local development

```sh
npm install
npm run dev
```
